# Error Handling

## Instructions
1. Detect invalid task IDs, missing required fields, or ambiguous commands.
2. Prompt the user for clarification if necessary.
3. Confirm before performing destructive actions like delete or update.

## Examples
- "Task ID 10 not found. Here are your current tasks: ..."
- "Please provide the task ID to update the task title."
- "Are you sure you want to delete 'Old task'? Confirm yes/no."

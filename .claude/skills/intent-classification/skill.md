# Intent Classification

## Instructions
1. Read the user's message carefully.
2. Identify the action the user wants: add, list, complete, delete, or update a task.
3. Detect ambiguous requests and ask for clarification if needed.
4. Map the identified intent to the corresponding MCP tool.

## Examples
- "Add a task to buy groceries" → intent: add_task
- "Show me all my tasks" → intent: list_tasks
- "Mark task 3 as complete" → intent: complete_task
- "Delete the meeting task" → intent: delete_task
- "Change task 1 to 'Call mom tonight'" → intent: update_task

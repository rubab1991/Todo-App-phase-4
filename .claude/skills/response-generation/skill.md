# Response Generation

## Instructions
1. After each action, generate a response confirming success or explaining errors.
2. Use friendly, natural language suitable for a chatbot.
3. Include task details, IDs, or status when relevant.

## Examples
- "Task 'Buy groceries' added successfully."
- "Task ID 5 not found. Please check your task list."
- "You have 3 pending tasks: Buy groceries, Call mom, Pay bills."

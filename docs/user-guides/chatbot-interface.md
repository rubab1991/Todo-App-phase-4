# Todo AI Chatbot User Guide

## Introduction

Welcome to the Todo AI Chatbot! This guide will help you understand how to use the chatbot interface to manage your tasks using natural language.

The Todo AI Chatbot allows you to interact with your task list conversationally. Simply type your requests in plain English, and the chatbot will help you manage your tasks.

## Getting Started

### Opening the Chat Interface

1. Look for the chatbot icon (💬) in the bottom-right corner of your screen
2. Click the icon to open the chat interface
3. The chat window will slide up from the corner
4. You can now start typing your requests

### Understanding the Interface

The chat interface consists of:

- **Chat History Window**: Shows your conversation with the AI
- **Message Input**: Where you type your requests
- **Send Button**: Sends your message to the AI
- **Close Button**: Closes the chat window (X)

## Basic Commands

### Adding Tasks

To add a task, simply tell the chatbot what you want to add:

- "Add task: Buy groceries"
- "Remember to call mom"
- "Create a new task to finish report"
- "Add task: Buy milk, bread, and eggs"

The chatbot will confirm: "Task 'Buy groceries' has been added successfully. ✅"

### Viewing Your Tasks

To see your current tasks:

- "Show my tasks"
- "List pending tasks"
- "What tasks do I have?"
- "Show completed tasks"

The chatbot will respond with a count: "You have 3 tasks."

### Completing Tasks

To mark a task as complete:

- "Complete task #1"
- "Finish task #2"
- "Done with task #3"
- "Mark task #1 as completed"

The chatbot will confirm: "Task #1 has been completed. ✅"

### Updating Tasks

To change a task title or description:

- "Update task 1 to buy vegetables"
- "Change task title to something else"
- "Rename task #2 to 'Call dentist'"

The chatbot will confirm: "Task #1 has been updated successfully. 📝"

### Deleting Tasks

To remove a task:

- "Delete task #1"
- "Remove task #2"
- "Cancel task #3"

The chatbot will confirm: "Task #1 has been deleted. ❌"

## Advanced Features

### Natural Language Processing

The chatbot understands natural language, so you can be flexible with your phrasing:

- "Could you please add a task to schedule dentist appointment?"
- "I'm done with the grocery shopping task"
- "Can you show me all my pending tasks?"
- "Change the workout task to tomorrow evening"

### Task Referencing

When referring to specific tasks, you can use:

- Task numbers: "Complete task #1"
- Partial titles: "Complete the grocery task"
- Relative references: "Complete the last task I added"

### Conversation Context

The chatbot maintains context within the conversation:

- If you say "Show tasks" and then "Complete #1", it remembers the task list
- Follow-up questions work naturally: "What was the second task?" after viewing your list

## Chat Interface Features

### Message History

- Your conversation history is preserved between sessions
- Previous interactions are accessible when returning to the chatbot
- Context is maintained for ongoing task management

### Loading Indicators

- When the AI is processing your request, you'll see a "typing" indicator
- This typically takes 2-5 seconds depending on complexity

### Error Handling

If something goes wrong:

- The chatbot will provide a clear error message
- Try rephrasing your request if needed
- Common issues are usually resolved by being more specific

## Best Practices

### Clear Instructions

- Be as specific as possible when referencing tasks
- Use task numbers when you have multiple similar tasks
- Include key details in your task titles

### Task Organization

- Keep task titles concise but descriptive
- Use consistent terminology for similar tasks
- Regularly complete or delete tasks you no longer need

### Natural Language Tips

- The chatbot understands variations of commands
- You can combine multiple requests: "Add task: Buy groceries, then show my tasks"
- Be patient if your first phrasing doesn't work as expected

## Troubleshooting

### Common Issues

**Task not recognized**: If you get an error about a task not being found, double-check the task number or try rephrasing.

**Command not understood**: If the chatbot doesn't understand your request, try using simpler language or one of the example commands above.

**Response takes too long**: Wait up to 10 seconds for a response. If nothing happens, refresh the page and try again.

### Getting Help

- Use the "help" command to get a list of available commands
- Try the example phrases in this guide
- Contact support if issues persist

## Privacy and Security

- Your task data is securely stored and only accessible to you
- Conversations are encrypted in transit
- The chatbot does not share your personal information
- All data is handled according to our privacy policy

## Tips for Success

1. **Start simple**: Begin with basic commands like "Add task: [title]"
2. **Be specific**: Use task numbers when dealing with multiple tasks
3. **Check confirmation**: Look for the ✅, ❌, or 📝 indicators to confirm actions
4. **Experiment**: Try different phrasings to see what works best
5. **Keep tasks manageable**: Break large tasks into smaller, specific ones
